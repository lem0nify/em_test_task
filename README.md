# Тестовое задание для Effective Mobile

[Описание задания и требований](https://raw.githubusercontent.com/lem0nify/em_test_task/main/task.pdf)

## Запуск

```
$ git clone https://github.com/lem0nify/em_test_task.git
$ cd em_test_task
$ docker compose up -d
```

## Тестирование

```
$ bats test.bats
```
*Необходимо установить **bats** и **jq***.
